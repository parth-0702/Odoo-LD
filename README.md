GLOBETROTTER — PREMIUM PERSONALIZED TRAVEL PLANNING PLATFORM

Build a complete, production-quality web application called GlobeTrotter.

GlobeTrotter is a personalized, intelligent and collaborative travel-planning platform that helps users dream, design, organize, visualize and share multi-city trips.

The application must satisfy the provided GlobeTrotter hackathon requirements while taking visual inspiration from premium travel websites such as:

TREVO Digital Travel Landing Page

Advanturo Adventure Travel Website

The provided GlobeTrotter visual reference

IMPORTANT:

The Dribbble references are ONLY visual inspiration.

DO NOT copy their layouts pixel-for-pixel.

DO NOT copy their branding, text, illustrations or exact design.

Create an ORIGINAL GlobeTrotter identity using the same level of polish, visual storytelling, typography, whitespace, imagery and premium travel aesthetics.

1. CORE PRODUCT REQUIREMENT

GlobeTrotter must allow a user to:

Create an account

Log in

Create customized multi-city trips

Add travel stops/cities

Assign dates and duration to each stop

Search and discover cities

Search and discover activities

Add activities to itinerary days

Reorder cities/stops

View the complete itinerary

View itinerary as a calendar/timeline

Track estimated trip expenses

See detailed budget breakdown

Detect over-budget situations

Share trips publicly

Allow others to view shared itineraries

Allow users to copy a shared trip

Manage profile and preferences

Save destinations

Provide an optional admin analytics dashboard

The application should make travel planning feel exciting rather than like filling out a complicated form.

2. IMPORTANT DESIGN PRINCIPLE

This is NOT just a landing page.

Build TWO connected experiences:

EXPERIENCE A — Premium Public Landing Page

This is the cinematic marketing/discovery experience inspired by TREVO and Advanturo.

EXPERIENCE B — Actual Travel Planning Application

After Login / Signup, users enter the functional GlobeTrotter application where they can manage trips, itineraries, activities, budgets and sharing.

Both experiences must share the same design system.
